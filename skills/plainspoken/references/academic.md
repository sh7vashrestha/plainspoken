# Extra rules for academic papers

1. Research questions should name every gap the introduction states. Each results subsection opens by saying which question it answers, in the question's own words.
2. After a list of gaps, the next paragraph names the gap or says "To answer these questions". Never a bare "this gap".
3. No forward references ("see Section 6", "below"). Backward references are fine. Point to a whole section once, then use names.
4. A summary sentence may go uncited when the next sentence carries the citations. Cite it directly if that next sentence could be moved or cut.
5. Write "finds 0.80 of the cases" before "achieves a recall of 0.80". Give the words first, the symbol after.
6. Mark any analysis added after the main results were fixed as post hoc.
7. Do not mix results from different test protocols in one table.
8. Table and figure labels start with a capital letter. Captions are short and explain every symbol or mark (bold, asterisk, dashed outline).
9. Abstracts: problem, what you did, what you found (with the main number), why it matters. No "In this paper, we delve into".
